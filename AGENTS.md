# Работа с mafia-web

- Здесь находятся интерфейс организатора и судейский пульт. Судья обычно
  работает за компьютером. API владеет правилами, таймером и правами доступа.
- Используйте React, TanStack Query, shadcn/ui на Base UI и Tailwind. Общие
  примитивы хранятся в `src/components/ui`, токены темы — в `src/theme.css`.
- Получайте сгенерированный OpenAPI из конкретной ревизии `mafia-api`.
  Обновите `contracts/openapi.json`, затем запустите `make generate` и включите
  сгенерированные типы в коммит. Запросы идут по относительным `/api/v1/`.
- После изменений запускайте `make check`. Сквозная проверка с реальным
  API и PostgreSQL находится в `mafia-ops`. Для тестов используйте
  синтетические данные.
